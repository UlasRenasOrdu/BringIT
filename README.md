## Getting Started

1. Clone the repository:
   `git clone https://github.com/UlasRenasOrdu/BringIT.git`
2. Open the project in Android Studio.
3. Create a Firebase project, register an Android app with the package name
   [com.example.bringit], and place your own `google-services.json` in the `app/` folder.
4. Run on a device or emulator.
